## Блок 1: Python, интерпретатор и инструменты (10 мин)

### Что такое Python

Python — высокоуровневый язык программирования общего назначения. «Высокоуровневый»
означает, что вы описываете, **что** нужно сделать, а не как устроена память компьютера.

Почему именно он для первого языка:

| Преимущество | Что это значит на практике |
|--------------|----------------------------|
| Читаемость | Код похож на английский текст, его легко читать через месяц после написания |
| Низкий порог входа | Первую работающую программу можно написать в первые 10 минут |
| Много библиотек | Готовые решения почти для всего: сайты, данные, автоматизация, ML |
| Кроссплатформенность | Одна и та же программа работает на Windows, macOS и Linux |
| Большое сообщество | На любой вопрос уже есть ответ на Stack Overflow и в документации |

Где применяется: веб-разработка, анализ данных и машинное обучение, автоматизация
рутины и скрипты, тестирование, научные расчёты, боты и парсеры.

### Интерпретатор

Компьютер не понимает текст программы напрямую. Его читает и выполняет **интерпретатор** —
программа с именем `python`, которую вы установили.

```
ваш файл hello.py  →  интерпретатор python  →  результат на экране
```

Ключевая особенность: интерпретатор выполняет инструкции **по очереди, сверху вниз**.
Дошёл до строки — выполнил её — перешёл к следующей. Если в середине файла ошибка,
всё, что было до неё, уже успеет выполниться.

### Где писать код

Код — это обычный текст, поэтому подойдёт **любой** редактор. Выбор инструмента
не влияет на то, как работает программа:

- **Простые текстовые редакторы** — Блокнот, TextEdit, nano. Работают всегда, но без подсказок
- **Редакторы кода** — [VS Code](https://code.visualstudio.com/), [Zed](https://zed.dev/),
  Sublime Text. Подсветка синтаксиса, автодополнение, запуск кода из редактора
- **IDE (интегрированные среды разработки)** — [PyCharm](https://www.jetbrains.com/pycharm/).
  Всё то же плюс отладчик, рефакторинг, работа с проектами «из коробки»

> **Рекомендация для курса:** VS Code с расширением Python — бесплатно, быстро ставится,
> одинаково работает на всех системах. Но если вам привычнее другое — используйте своё.
> На семинарах мы запускаем программы **из терминала**, это не зависит от редактора.

> **Подробнее об установке Python и редакторов:** см. [`docs/installation.md`](../../docs/installation.md)

## Блок 2: Первая программа (15 мин)

### Интерактивный режим (REPL)

Наберите в терминале `python` (или `python3`) — откроется интерактивный режим:

```
>>> 2 + 2
4
>>> print("Привет!")
Привет!
>>> exit()
```

Приглашение `>>>` означает «жду инструкцию». Интерпретатор выполняет её сразу и
показывает результат. Это удобно, чтобы что-то быстро проверить.

Минус интерактивного режима: программа нигде не сохраняется. Поэтому настоящие
программы пишут в файлы.

### Программа в файле

**Модуль** — это файл с расширением `.py`, в котором записаны инструкции.
Создайте файл `hello.py`:

```python
print("Hello, world!")
```

и запустите его из терминала (из той папки, где лежит файл):

```bash
python hello.py
```

### Функция print()

`print()` — встроенная функция вывода. Круглые скобки означают «вызвать функцию»,
а то, что внутри, — **аргументы**, то есть данные для неё.

```python
print("Hello, world!")  # Hello, world!
print("Python", "версия", 3.12)  # Python версия 3.12 (значения через пробел)
print("2026", "09", "28", sep="-")  # 2026-09-28 (свой разделитель)
print("Загрузка", end="...")  # без перевода строки в конце
print()  # пустая строка
```

Строка — это текст в кавычках, двойных или одинарных: `"Привет"` и `'Привет'` —
одно и то же.

## Блок 3: Переменные, выражения и операции (15 мин)

### Переменная

**Переменная** — это имя для значения. Знак `=` — это **операция присваивания**,
а не математическое равенство: «сохрани значение справа под именем слева».

```python
name = "Анна"
age = 19

age = 20  # старое значение просто забывается
next_year = age + 1
```

### Правила именования

| Можно | Нельзя | Не стоит |
|-------|--------|----------|
| `user_name`, `total2`, `_temp` | `2total` (начинается с цифры) | `class`, `print`, `input` (занятые имена) |
| Буквы, цифры, `_` | `user-name` (дефис — это минус) | `a`, `x1`, `dannye` (непонятно, что внутри) |

Регистр важен: `age` и `Age` — разные переменные. По соглашению
[PEP 8](https://peps.python.org/pep-0008/) имена переменных пишут строчными буквами,
слова разделяют подчёркиванием: `total_price`, `student_count`.

### Инструкция, выражение, операция

- **Инструкция** — команда, которую интерпретатор выполняет: `age = 20`, `print(age)`
- **Выражение** — то, что можно **вычислить**: `2 + 2`, `age * 2`, `"при" + "вет"`
- **Операция** — действие внутри выражения: `+`, `-`, `*`, `/`

### Операции с числами

```python
a = 17
b = 5

a + b  # 22
a - b  # 12
a * b  # 85
a / b  # 3.4 — деление всегда даёт дробное число
a // b  # 3 — целая часть от деления
a % b  # 2 — остаток от деления
a**2  # 289 — возведение в степень
```

Приоритет операций и скобки работают как в математике.

### Операции со строками

```python
"Иван" + " " + "Петров"  # Иван Петров — склеивание (конкатенация)
"-" * 30  # ------... — повторение
```

### Типы значений

У каждого значения есть **тип**: `str` (строка), `int` (целое число),
`float` (дробное число). Узнать тип помогает функция `type()`.

```python
type("текст")  # <class 'str'>
type(42)  # <class 'int'>
type(3.14)  # <class 'float'>
```

Складывать строку с числом нельзя — это разные типы:

```python
print("возраст: " + 20)  # TypeError: can only concatenate str (not "int") to str
```

## Блок 4: Ввод данных и преобразование типов (15 мин)

### Функция input()

`input()` показывает приглашение, ждёт ввода с клавиатуры и нажатия Enter,
а затем возвращает введённое значение:

```python
name = input("Как вас зовут? ")
print("Привет,", name)
```

### Главное правило: input() всегда возвращает строку

Даже если пользователь ввёл `5`, в переменной окажется строка `"5"`:

```python
value = input("Введите число: ")  # пользователь ввёл 5
print(value * 2)  # 55, а не 10!
```

Чтобы считать, строку нужно преобразовать в число:

```python
number = int(value)  # "5" → 5 (целое)
weight = float("62.5")  # "62.5" → 62.5 (дробное)
text = str(42)  # 42 → "42" (обратно в строку)
```

Обычно преобразование пишут сразу вокруг `input()`:

```python
age = int(input("Сколько вам лет? "))
```

Если пользователь введёт не число, программа остановится с ошибкой
`ValueError`. Как обрабатывать такие ситуации — разберём на **семинаре 8**.

### f-строки

Буква `f` перед кавычками разрешает подставлять значения переменных прямо в текст —
внутри фигурных скобок. Внутри скобок можно писать и выражения:

```python
name = "Анна"
age = 19

print(f"{name}, через 10 лет вам будет {age + 10}")
# Анна, через 10 лет вам будет 29
```

Без f-строки то же самое пришлось бы собирать вручную:

```python
print(name + ", через 10 лет вам будет " + str(age + 10))
```

## Блок 5: Комментарии, отступы и ошибки (15 мин)

### Комментарии

Всё после символа `#` интерпретатор игнорирует. Комментарии пишут для людей —
они объясняют **зачем**, а не пересказывают код:

```python
price = 500  # цена одного билета, руб.

# Хороший комментарий объясняет замысел:
# скидка действует только в первый месяц после регистрации

# print("отключено") — так можно временно убрать код, не удаляя его
```

### Отступы

В большинстве языков блоки кода выделяют фигурными скобками, а в Python — **отступами**
(4 пробела). Строки с одинаковым отступом образуют один блок:

```python
temperature = 30

if temperature > 25:
    print("Жарко!")  # тело условия — выполнится, только если условие истинно
    print("Возьмите воды")  # тот же блок

print("Эта строка выполняется всегда")  # уже вне блока
```

> Конструкцию `if` подробно разберём на **семинаре 2** — здесь она нужна только
> чтобы показать, как работают отступы.

Лишний отступ — ошибка `IndentationError: unexpected indent`.
Забытый отступ после двоеточия — `IndentationError: expected an indented block`.

### Как читать ошибки

Ошибки — нормальная часть работы, а не признак провала. Python всегда пишет, **где**
и **что** ему не понравилось. Читать сообщение нужно **с конца**: последняя строка — суть.

| Ошибка | Что значит | Пример |
|--------|------------|--------|
| `SyntaxError` | Опечатка в тексте программы | `print("привет"` — не закрыта скобка |
| `NameError` | Имя не существует | `print(nmae)` вместо `name` |
| `TypeError` | Операция не подходит для этих типов | `"возраст: " + 20` |
| `ValueError` | Тип подходит, а значение нет | `int("привет")` |

## Блок 6: Собираем программы целиком (10 мин)

Всё, что нужно для настоящей маленькой программы, у вас уже есть: ввод, вычисление, вывод.
Почти любая программа устроена по этой схеме:

```
получить данные (input)  →  обработать (операции)  →  показать результат (print)
```

**Сложение двух чисел:**

```python
first_number = int(input("Введите первое число: "))
second_number = int(input("Введите второе число: "))
total = first_number + second_number
print(f"{first_number} + {second_number} = {total}")
```

**Приветствие по имени:**

```python
user_name = input("Как вас зовут? ")
birth_year = int(input("В каком году вы родились? "))
print(f"Здравствуйте, {user_name}! В 2026 году вам исполняется {2026 - birth_year}.")
```

> **Подробнее:** см. файл [`examples/05_simple_programs.py`](examples/05_simple_programs.py)

## Итоги

Что вы теперь умеете:

- `print()` — вывести данные; `input()` — получить данные от пользователя
- Переменная хранит значение, `=` — это присваивание
- `input()` возвращает строку, для вычислений нужен `int()` или `float()`
- f-строки удобно собирают текст со значениями переменных
- Отступы в Python — часть синтаксиса, а не оформление
- Сообщение об ошибке нужно дочитать до последней строки — там суть

**Дальше:** на семинаре 2 разберём типы данных подробнее и добавим в программы
ветвления (`if`) и циклы (`for`, `while`) — тогда программы начнут «принимать решения».
