## Часть 2: Переменные, выражения и операции

> **Теория:** [README.md — Блок 3](../README.md#блок-3-переменные-выражения-и-операции-15-мин) | **Примеры:** [`examples/02_variables_and_expressions.py`](../examples/02_variables_and_expressions.py)

### Задание 2.1

Какие из этих имён переменных допустимы в Python, а какие нет? Для недопустимых
объясните почему.

```
user_name    2nd_place    _count    my-variable    Total
print        имя_файла    x1        1x             student count
```

<details>
<summary>Решение</summary>

| Имя | Допустимо? | Комментарий |
|-----|-----------|-------------|
| `user_name` | ✅ | Хорошее имя по PEP 8 |
| `2nd_place` | ❌ | Имя не может начинаться с цифры |
| `_count` | ✅ | Подчёркивание в начале разрешено |
| `my-variable` | ❌ | Дефис — это операция вычитания |
| `Total` | ✅ | Работает, но по PEP 8 переменные пишут строчными: `total` |
| `print` | ⚠️ | Технически можно, но так вы «сломаете» функцию `print()` в своей программе |
| `имя_файла` | ⚠️ | Python разрешает кириллицу, но так делать не стоит: имена в коде пишут по-английски |
| `x1` | ✅ | Допустимо, но непонятно, что внутри |
| `1x` | ❌ | Начинается с цифры |
| `student count` | ❌ | Пробел в имени недопустим, нужно `student_count` |

</details>

## Часть 4: Комментарии, отступы и ошибки

> **Теория:** [README.md — Блок 5](../README.md#блок-5-комментарии-отступы-и-ошибки-15-мин) | **Примеры:** [`examples/04_syntax_basics.py`](../examples/04_syntax_basics.py)

### Задание 4.1

Что выведет эта программа? Обратите внимание на отступы.

```python
score = 90

if score > 50:
    print("Зачёт")
    print("Поздравляем")

print("Конец")
```

А что изменится, если у последней строки сделать отступ в 4 пробела?

<details>
<summary>Решение</summary>

Программа выведет:

```
Зачёт
Поздравляем
Конец
```

Если у `print("Конец")` сделать отступ, она войдёт в тело `if` и будет выводиться
только при `score > 50`. При `score = 10` эта строка не выполнилась бы.

</details>

### Задание 4.2

Для каждого фрагмента назовите тип ошибки и исправьте её.

```python
# а)
print("Привет, мир!"

# б)
name = "Анна"
print(nmae)

# в)
age = 20
print("Возраст: " + age)

# г)
value = int("двадцать")
```

<details>
<summary>Подсказка</summary>

Четыре типичные ошибки: `SyntaxError`, `NameError`, `TypeError`, `ValueError`.
Каждая встречается ровно один раз.

</details>

<details>
<summary>Решение</summary>

**а) `SyntaxError`** — не закрыта круглая скобка:

```python
print("Привет, мир!")
```

**б) `NameError`** — опечатка в имени переменной (`nmae` вместо `name`):

```python
print(name)
```

**в) `TypeError`** — нельзя склеить строку и число. Нужно преобразовать число
в строку или воспользоваться f-строкой:

```python
print("Возраст: " + str(age))
print(f"Возраст: {age}")  # так лучше
```

**г) `ValueError`** — тип аргумента верный (строка), но значение не является числом.
Исправить можно только изменив данные: `int("20")`.

</details>

### Задание 6.1

Программа запрашивает количество секунд и выводит их в формате `часы:минуты:секунды`.
Например, `3725` → `1 ч 2 мин 5 сек`.

<details>
<summary>Подсказка</summary>

В часе 3600 секунд. Сначала выделите часы через `//`, затем из остатка (`%`) —
минуты и секунды.

</details>

<details>
<summary>Решение</summary>

```python
total_seconds = int(input("Введите количество секунд: "))

hours = total_seconds // 3600
rest = total_seconds % 3600
minutes = rest // 60
seconds = rest % 60

print(f"{hours} ч {minutes} мин {seconds} сек")
```

</details>

### Задание 6.2

Калькулятор поездки на такси: подача стоит 150 руб., каждый километр — 22 руб.
Программа запрашивает расстояние в километрах и выводит стоимость, округлённую
до целых рублей.

<details>
<summary>Подсказка</summary>

Округлить число помогает встроенная функция `round()`: `round(123.456)` → `123`,
`round(123.456, 1)` → `123.5`.

</details>

<details>
<summary>Решение</summary>

```python
BOARDING_PRICE = 150  # константа: стоимость подачи, руб.
PRICE_PER_KM = 22

distance = float(input("Расстояние в км: "))
total = BOARDING_PRICE + PRICE_PER_KM * distance

print(f"Стоимость поездки: {round(total)} руб.")
```

Имена в верхнем регистре — соглашение для констант, то есть значений, которые
в программе не меняются.

</details>
