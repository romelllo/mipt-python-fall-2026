## Блок 1: Типы данных: строки и логический тип (10 мин)

### Многострочные строки и спецсимволы

Строку на несколько строк удобно записывать в **тройных кавычках**:

```python
menu = """Меню:
  - кофе
  - чай"""
print(menu)
```

Внутри обычной строки перенос и табуляцию задают **спецсимволы** — они начинаются
с обратного слэша:

| Спецсимвол | Что делает |
|------------|------------|
| `\n` | Перевод строки |
| `\t` | Табуляция (выравнивание в столбик) |
| `\\` | Сам обратный слэш |
| `\"` | Кавычка того же типа, что и у строки |

```python
print("Первая строка\nВторая строка")
print("Имя:\tАнна")
print("Путь: C:\\Users\\student")
```

### Логический тип bool

У типа `bool` всего два значения: `True` и `False` (обязательно с заглавной буквы).
Их возвращают **операции сравнения**:

```python
print(5 > 3)  # True
print(3 > 5)  # False
print(5 == 5)  # True  — равно
print(5 == 3)  # False
print(5 != 3)  # True  — не равно
print(5 != 5)  # False
print(5 >= 5)  # True  — больше или равно
print(5 <= 4)  # False
```

> **Главная путаница новичков:** `=` — это присваивание (`age = 18`),
> а `==` — сравнение (`age == 18`). В условиях нужно именно `==`.

Строки сравнивать тоже можно — на равенство и по алфавиту:

```python
print("Привет" == "привет")  # False — регистр важен
print("яблоко" > "банан")  # True — «я» идёт после «б»
```

### Логические операторы и in

| Оператор | Истинно, когда | Пример |
|----------|----------------|--------|
| `and` | истинны **оба** условия | `age >= 18 and has_ticket` |
| `or` | истинно **хотя бы одно** | `is_holiday or is_weekend` |
| `not` | условие **ложно** | `not is_adult` |
| `in` | строка входит в другую строку | `"кот" in "мой кот спит"` |

```python
age = 19
has_ticket = True
is_holiday = False

print(age >= 18 and has_ticket)  # True  — истинны оба условия
print(age >= 18 and is_holiday)  # False — второе условие ложно
print(age >= 18 or is_holiday)  # True  — достаточно одного истинного
print(is_holiday or has_ticket)  # True
print(not has_ticket)  # False — отрицание True
print(not is_holiday)  # True  — отрицание False
print("кот" in "мой кот спит")  # True
print("пёс" in "мой кот спит")  # False
```

> Запомнить легко так: `and` — строгий, ему нужны **все** условия;
> `or` — добродушный, ему хватит **любого**.

> **Подробнее:** см. файл [`examples/01_data_types.py`](examples/01_data_types.py)

## Блок 2: Условия: if, elif, else (10 мин)

### Зачем нужны условия

До сих пор наши программы выполнялись строго сверху вниз: интерпретатор читал инструкции
одну за другой и выполнял **все** подряд. Но полезная программа почти всегда должна
**принимать решения**: пустить на сеанс или нет, дать скидку или взять полную цену,
написать «чётное» или «нечётное».

Условие — это **развилка** в программе:

```
                     ┌── истинно ──→ выполнить один блок кода
  проверить условие ─┤
                     └── ложно ────→ выполнить другой блок (или ничего не делать)
```

В быту мы рассуждаем так же: «если идёт дождь — возьму зонт, иначе — очки». В программе
«идёт дождь» — это выражение, которое даёт `True` или `False`, то есть ровно тот самый
тип `bool` из первого блока. Поэтому логический тип и условия изучают рядом:
`bool` отвечает на вопрос «истинно ли это?», а `if` решает, что с ответом делать.

Две вещи, которые стоит понять сразу:

- **Развилка не заканчивает программу.** После ветвления выполнение продолжается
  с общей строки — условие лишь выбирает, какие строки выполнить, а какие пропустить
- **Границы ветки задаёт отступ.** Какие строки относятся к ветке, а какие уже нет,
  Python понимает по отступу (это разбирали на
  [семинаре 1](../seminar_01_intro_to_python/README.md#блок-5-комментарии-отступы-и-ошибки-15-мин))

### if и if-else

Условие позволяет программе выбирать, что делать. После условия ставится **двоеточие**,
а тело пишется с отступом в 4 пробела:

```python
age = 15

if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

Блок `else` необязателен: без него программа просто ничего не сделает, если условие ложно.

### if-elif-else

Когда вариантов больше двух, добавляют `elif` (сокращение от «else if»).
Python проверяет условия **сверху вниз** и выполняет **первое подошедшее** —
остальные даже не проверяются:

```python
score = 75

if score >= 90:
    print("Отлично")
elif score >= 75:
    print("Хорошо")
elif score >= 60:
    print("Удовлетворительно")
else:
    print("Неудовлетворительно")
```

> **Порядок условий важен.** Если поставить `score >= 60` первым, то при `score = 95`
> программа напечатает «Удовлетворительно»: это условие тоже истинно и сработает первым.

### Сложные условия

Несколько проверок объединяются через `and` и `or` — это обычно читается лучше,
чем вложенные `if`:

```python
if age >= 18 and has_ticket:
    print("Проходите в зал")
```

### Частые ошибки

| Ошибка | Что получится |
|--------|---------------|
| `if age = 18:` | `SyntaxError` — нужно `==` |
| `if age > 18` (без двоеточия) | `SyntaxError: expected ':'` |
| Нет отступа в теле | `IndentationError: expected an indented block` |
| `input("Возраст: ") > 18` | `TypeError` — строку нужно превратить в число через `int()` |

## Блок 3: Циклы: while, for, range() (10 мин)

### Зачем нужны циклы

Компьютер не устаёт и не ошибается от скуки — именно поэтому ему поручают однообразную
работу. Пока мы умеем только копировать строки:

```python
print(1)
print(2)
print(3)
```

Но вывести так числа до 1000 уже невозможно, а спрашивать у пользователя пароль,
«пока он не введёт правильный», — тем более: мы заранее не знаем, сколько раз придётся
спросить. Для этого есть **цикл** — конструкция, которая выполняет один и тот же блок
кода много раз. Один проход цикла называют **итерацией**.

В любом цикле есть три части, и о каждой нужно подумать, когда его пишешь:

1. **Что меняется** от шага к шагу — счётчик, очередной символ строки, очередной ввод
2. **Когда остановиться** — условие, при котором цикл закончится
3. **Тело** — код, который повторяется (пишется с отступом, как у `if`)

Забыть про второй пункт — классическая ошибка новичка: цикл, который никогда
не останавливается.

В Python два вида циклов, и выбор между ними сводится к одному вопросу:
**знаем ли мы заранее, сколько будет повторений?**

| Что известно | Цикл | Пример задачи |
|--------------|------|---------------|
| Количество повторений | `for` | напечатать таблицу умножения на 7 |
| Только условие остановки | `while` | спрашивать пароль, пока он неверный |

Строго говоря, любую задачу можно решить обоими циклами, но один из вариантов почти
всегда читается заметно лучше.

### while — пока условие истинно

`while` используют, когда заранее неизвестно, сколько будет повторений:

```python
count = 1
while count <= 5:
    print("Шаг", count)
    count += 1
```

Запись `count += 1` — **составной оператор присваивания**, короткая форма
для `count = count + 1`. Так же работают `-=`, `*=`, `/=`.

> **Осторожно с бесконечным циклом.** Если забыть строку `count += 1`, условие
> останется истинным навсегда и программа зависнет. Прервать её в терминале: **Ctrl+C**.

### for и range()

`for` используют, когда количество повторений известно. Чаще всего — вместе с `range()`:

| Запись | Что даёт |
|--------|----------|
| `range(5)` | `0 1 2 3 4` — от нуля, **не включая** 5 |
| `range(1, 6)` | `1 2 3 4 5` |
| `range(0, 11, 2)` | `0 2 4 6 8 10` — с шагом 2 |

```python
for number in range(1, 6):
    print(number)
```

Пройти можно и по строке — по одному символу:

```python
for letter in "Python":
    print(letter)
```

### Накопление результата

Приём, который встречается постоянно: завести переменную **до** цикла и менять её внутри.

```python
total = 0
for number in range(1, 101):
    total += number

print("Сумма чисел от 1 до 100:", total)
```

### break и continue

Эти два оператора управляют ходом цикла:

- `break` — досрочно выйти из цикла целиком
- `continue` — пропустить текущий шаг и перейти к следующему

```python
for number in range(1, 11):
    if number % 2 == 0:
        continue  # чётные пропускаем
    print(number)  # 1 3 5 7 9
```

> вынесены в раздел [«Для самостоятельной работы»](exercises/control_flow_practice.md#для-самостоятельной-работы) —
> там есть и подсказки, и решения.
