### Задание 1.2

Что выведет каждая строка? Сначала ответьте сами, потом проверьте в интерактивном режиме
(`python` в терминале).

```python
print(10 > 5)
print(10 == "10")
print("Кот" == "кот")
print(5 > 3 and 2 > 7)
print(5 > 3 or 2 > 7)
print(not 5 > 3)
print("при" in "привет")
```

<details>
<summary>Решение</summary>

```
True      10 действительно больше 5
False     число и строка не равны: это разные типы
False     регистр имеет значение
False     для and нужны оба условия, а 2 > 7 ложно
True      для or достаточно одного истинного
False     not переворачивает True в False
True      «при» входит в «привет»
```

</details>

### Задание 1.3

Заготовка: [`starter/task_1_3.py`](starter/task_1_3.py)

Программа спрашивает слово и выводит два ответа: длиннее ли оно пяти символов
и содержит ли букву «а».

```
Введите слово: программа
Длиннее пяти символов: True
Содержит букву «а»: True
```

<details>
<summary>Подсказка</summary>

Длину строки даёт `len(word)`, а вхождение буквы проверяет оператор `in`.
Печатать `True`/`False` можно напрямую: `print("...", len(word) > 5)`.

</details>

<details>
<summary>Решение</summary>

```python
word = input("Введите слово: ")

print("Длиннее пяти символов:", len(word) > 5)
print("Содержит букву «а»:", "а" in word)
```

</details>

### Задание 2.3

Заготовка: [`starter/task_2_3.py`](starter/task_2_3.py)

Цена билета в кино зависит от возраста:

| Возраст | Цена |
|---------|------|
| до 7 лет | бесплатно |
| 7–17 лет | 250 руб. |
| 18–64 года | 450 руб. |
| 65 лет и старше | 200 руб. |

Студентам от 18 до 64 лет билет обходится в 250 руб.

<details>
<summary>Подсказка</summary>

Условие для студентов проверяйте **внутри** диапазона 18–64: добавьте отдельную ветку
`elif is_student:` после того, как возраст 65+ уже отсеян.

</details>

<details>
<summary>Решение</summary>

```python
age = int(input("Сколько вам лет? "))
answer = input("Вы студент? (да/нет) ")
is_student = answer == "да"

if age < 7:
    price = 0
elif age < 18:
    price = 250
elif age >= 65:
    price = 200
elif is_student:
    price = 250
else:
    price = 450

print(f"Цена билета: {price} руб.")
```

Обратите внимание на строку `is_student = answer == "да"`: справа — сравнение,
его результат (`True` или `False`) записывается в переменную.

</details>

### Задание 3.1

Введите число: 7
7 x 1 = 7
7 x 2 = 14
...

### Задание 3.2

Заготовка: [`starter/task_3_2.py`](starter/task_3_2.py)

Обратный отсчёт: программа спрашивает число и печатает числа от него до 1,
а затем «Поехали!».

```
С какого числа считаем? 3
3
2
1
Поехали!
```

<details>
<summary>Подсказка</summary>

Условие цикла — `count > 0`. Внутри обязательно уменьшайте счётчик (`count -= 1`),

<details>
<summary>Решение</summary>

```python
count = int(input("С какого числа считаем? "))

while count > 0:

    count -= 1

```

### Задание 3.3

Заготовка: [`starter/task_3_3.py`](starter/task_3_3.py)

Программа спрашивает число N и выводит сумму всех целых чисел от 1 до N.

```
Введите N: 5
Сумма чисел от 1 до 5 = 15
```

<details>
<summary>Подсказка</summary>

Заведите переменную `total = 0` **до** цикла и прибавляйте к ней очередное число
внутри цикла: `total += number`.

</details>

<details>
<summary>Решение</summary>

```python
n = int(input("Введите N: "))

total = 0
for number in range(1, n + 1):
    total += number

print(f"Сумма чисел от 1 до {n} = {total}")
```

Обратите внимание на `n + 1`: без этого последнее число N не попадёт в сумму.

</details>

### Задание 4.1

Выведите числа от 1 до 30, но пропустите все, которые делятся на 3.

<details>
<summary>Подсказка</summary>

`continue` пропускает текущий шаг цикла и переходит к следующему.

</details>

<details>
<summary>Решение</summary>

```python
for number in range(1, 31):
    if number % 3 == 0:
        continue
    print(number)
```

</details>

### Задание 4.2

Найдите первое число, которое больше 100 и делится одновременно на 3 и на 7.
Как только нашли — выведите его и прекратите поиск.

<details>
<summary>Подсказка</summary>

Проверяйте числа подряд в цикле, а когда условие выполнится — выходите через `break`.
Делимость сразу на 3 и на 7 — это два условия через `and`.

</details>

<details>
<summary>Решение</summary>

```python
for number in range(101, 1000):
    if number % 3 == 0 and number % 7 == 0:
        print("Нашли:", number)
        break
```

Ответ — 105. То же самое можно записать одним условием: `number % 21 == 0`.

</details>

### Задание 4.3

Классическая задача FizzBuzz. Для чисел от 1 до 30 выведите:

- `Fizz` — если число делится на 3
- `Buzz` — если делится на 5
- `FizzBuzz` — если делится и на 3, и на 5
- само число — во всех остальных случаях

<details>
<summary>Подсказка</summary>

Проверку «и на 3, и на 5» нужно поставить **первой**, иначе до неё дело не дойдёт.

</details>

<details>
<summary>Решение</summary>

```python
for number in range(1, 31):
    if number % 3 == 0 and number % 5 == 0:
        print("FizzBuzz")
    elif number % 3 == 0:
        print("Fizz")
    elif number % 5 == 0:
        print("Buzz")
    else:
        print(number)
```

</details>

### Задание 4.4

Программа спрашивает слово и считает, сколько в нём гласных букв.

```
Введите слово: программирование
Гласных букв: 7
```

<details>
<summary>Подсказка</summary>

Пройдите по строке циклом `for letter in word` и проверяйте `letter in "аеёиоуыэюя"`.
Чтобы заглавные буквы тоже считались, приведите слово к нижнему регистру
методом `word.lower()`.

</details>

<details>
<summary>Решение</summary>

```python
word = input("Введите слово: ").lower()
vowels = "аеёиоуыэюя"

count = 0
for letter in word:
    if letter in vowels:
        count += 1

print("Гласных букв:", count)
```

</details>

### Задание 4.5

Игра «Угадай число». Загаданное число записано в переменной. Программа просит вводить
числа, пока пользователь не угадает, и после каждой попытки подсказывает «больше»
или «меньше». В конце — сколько попыток потребовалось.

<details>
<summary>Подсказка</summary>

Здесь удобен `while True` с выходом через `break`, когда число угадано.
Счётчик попыток увеличивайте на каждой итерации.

</details>

<details>
<summary>Решение</summary>

```python
secret = 42
attempts = 0

while True:
    guess = int(input("Ваше число: "))
    attempts += 1

    if guess == secret:
        print(f"Угадали за {attempts} попыток!")
        break
    elif guess < secret:
        print("Загаданное число больше")
    else:
        print("Загаданное число меньше")
```

</details>

### Задание 4.6

Программа спрашивает год и определяет, високосный ли он. Год високосный, если он делится
на 4, но не делится на 100, — либо если делится на 400.

<details>
<summary>Подсказка</summary>

Всё условие записывается одним логическим выражением: две проверки через `and`,
объединённые с третьей через `or`. Скобки помогут не запутаться.

</details>

<details>
<summary>Решение</summary>

```python
year = int(input("Введите год: "))

is_leap = (year % 4 == 0 and year % 100 != 0) or year % 400 == 0

if is_leap:
    print(f"{year} — високосный год")
else:
    print(f"{year} — обычный год")
```

Проверьте себя: 2024 — високосный, 1900 — нет, 2000 — да.

</details>
