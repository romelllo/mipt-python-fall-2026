## Блок 1: Списки (10 мин)

### Зачем нужны коллекции

До сих пор одна переменная хранила одно значение. Этого хватает, пока значений мало:

```python
student_1 = "Анна"
student_2 = "Иван"
student_3 = "Пётр"
```

Но если студентов тридцать, такой код писать невозможно: переменные нельзя перебрать
циклом, их количество нельзя узнать, новую нельзя добавить во время работы программы.

**Коллекция** — это одна переменная, которая хранит много значений сразу. В Python их
несколько, и отличаются они ответом на два вопроса: **важен ли порядок элементов**
и **как до элемента добираться**.

| Коллекция | Как обращаются к элементу | Когда использовать |
|-----------|---------------------------|--------------------|
| Список (`list`) | по номеру: `students[0]` | упорядоченный набор однотипных значений |
| Строка (`str`) | по номеру: `word[0]` | текст; по сути — последовательность символов |
| Словарь (`dict`) | по ключу: `student["name"]` | данные с именами: «имя → значение» |
| Кортеж (`tuple`) | по номеру, но менять нельзя | набор значений, который не должен меняться |
| Множество (`set`) | никак, только проверка `in` | уникальные элементы, проверка принадлежности |

Сегодня подробно разбираем первые три — они нужны чаще всего.

### Создание и длина

```python
fruits = ["яблоко", "банан", "вишня"]
numbers = [10, 25, 3]
empty = []

print(len(fruits))  # 3
```

### Индексация

Элементы нумеруются **с нуля**. Отрицательные индексы считают с конца:

```
индекс:     0         1        2
         ["яблоко", "банан", "вишня"]
с конца:   -3        -2       -1
```

```python
print(fruits[0])  # яблоко
print(fruits[-1])  # вишня — последний элемент
```

Обращение к несуществующему индексу даёт `IndexError: list index out of range`.

### Срезы

Запись `list[start:stop]` берёт элементы с `start` по `stop`, **не включая** `stop` —
так же, как `range(start, stop)`:

```python
letters = ["a", "b", "c", "d", "e", "f"]

letters[1:4]  # ['b', 'c', 'd']
letters[:3]  # ['a', 'b', 'c']  — с начала
letters[3:]  # ['d', 'e', 'f']  — до конца
letters[::2]  # ['a', 'c', 'e']  — каждый второй
letters[::-1]  # ['f', 'e', 'd', 'c', 'b', 'a'] — в обратном порядке
```

### Изменение списка

Список **изменяемый**: элемент можно заменить, добавить или удалить.

| Действие | Запись | Что делает |
|----------|--------|------------|
| Заменить | `fruits[0] = "груша"` | меняет элемент по индексу |
| Добавить в конец | `fruits.append("киви")` | самый частый способ |
| Вставить по индексу | `fruits.insert(1, "слива")` | сдвигает остальные вправо |
| Удалить по значению | `fruits.remove("банан")` | удаляет первое совпадение |
| Удалить последний | `fruits.pop()` | удаляет и **возвращает** элемент |
| Отсортировать | `numbers.sort()` | сортирует список на месте |

`append`, `insert`, `remove` — это **методы**: действия, которые вызываются
у самого объекта через точку.

### Перебор

```python
total = 0
for number in numbers:
    total += number

print("Сумма:", total)
print("вишня" in fruits)  # True
```

## Блок 2: Строки как последовательность. split() и join() (10 мин)

### Строка — это последовательность символов

Со строкой работают те же индексы и срезы, что и со списком, — отдельных правил
запоминать не нужно:

```python
word = "Python"

word[0]  # P
word[-1]  # n
word[:3]  # Pyt
word[::-1]  # nohtyP — задом наперёд
len(word)  # 6
```

### Главное отличие: строка неизменяема

Элемент списка заменить можно, а символ строки — нет:

```python
word[0] = "J"  # TypeError: 'str' object does not support item assignment
```

Вместо изменения собирают **новую** строку:

```python
new_word = "J" + word[1:]  # Jython
```

### Коды символов

Каждому символу соответствует число — код в таблице Unicode:

```python
ord("A")  # 65 — код символа
chr(66)  # B  — символ по коду
```

### split() — из строки в список

Метод `split()` разрезает строку по разделителю:

```python
"мама мыла раму".split()  # ['мама', 'мыла', 'раму'] — по пробелам
"Анна,19,ФРКТ".split(",")  # ['Анна', '19', 'ФРКТ']
```

Это основной способ разобрать строку на части: посчитать слова, разобрать строку
с данными, обработать пользовательский ввод из нескольких значений.

### join() — из списка в строку

Метод `join()` собирает список строк в одну. Вызывается **у разделителя**:

```python
names = ["Анна", "Иван", "Пётр"]

", ".join(names)  # Анна, Иван, Пётр
" и ".join(names)  # Анна и Иван и Пётр
```

`join()` работает только со списком строк: `", ".join([1, 2, 3])` даст `TypeError`.

> **Подробнее:** см. файл [`examples/02_strings.py`](examples/02_strings.py)

## Блок 3: Словари (10 мин)

### Зачем нужен словарь

В списке элемент находят по номеру. Но номер почти ничего не говорит о содержимом:

```python
student = ["Анна", "Б01-123", 1]
print(student[1])  # что такое [1]? группа? курс?
```

Словарь хранит **пары «ключ — значение»**, и обращение к данным становится понятным:

```python
student = {
    "name": "Анна",
    "group": "Б01-123",
    "course": 1,
}

print(student["group"])  # Б01-123
```

Ключ — обычно строка, значение — что угодно. Порядок элементов в словаре не важен:
к ним не обращаются по номеру.

### Основные операции

| Действие | Запись |
|----------|--------|
| Получить значение | `student["name"]` |
| Получить безопасно | `student.get("email", "не указан")` |
| Добавить или изменить | `student["email"] = "a@example.com"` |
| Удалить | `del student["email"]` |
| Проверить **ключ** | `"name" in student` |
| Количество пар | `len(student)` |

Обращение к несуществующему ключу даёт `KeyError`. Чтобы этого избежать, используют
`get()`: он вернёт `None` или указанное значение по умолчанию.

### Перебор словаря

```python
prices = {"кофе": 180, "чай": 120}

for item in prices:  # по ключам
    print(item, prices[item])

for item, price in prices.items():  # сразу пары
    print(f"{item}: {price} руб.")
```

| Метод | Что даёт |
|-------|----------|
| `prices.keys()` | ключи |
| `prices.values()` | значения |
| `prices.items()` | пары «ключ — значение» |

> **Подробнее:** см. файл [`examples/03_dicts.py`](examples/03_dicts.py)

### Кортежи (tuple)

Кортеж — это список, который нельзя изменить. Записывается в круглых скобках:

```python
point = (10, 20)
print(point[0])  # 10
point[0] = 5  # TypeError — кортеж неизменяем
```

Индексы, срезы, `len()`, перебор и `in` работают так же, как у списка. Множественное
присваивание с семинара 1 (`a, b = b, a`) — это тоже кортежи.

### Множества (set)

Множество хранит только **уникальные** элементы и не хранит порядок:

```python
numbers = [1, 2, 2, 3, 3, 3]
unique = set(numbers)  # {1, 2, 3}
```

Отсюда главный приём: `set()` убирает дубликаты. Доступны операции из теории множеств:
`|` — объединение, `&` — пересечение, `-` — разность, `^` — симметрическая разность.

### Списочные выражения (list comprehensions)

Короткая запись для создания списка на основе другого списка или `range()`:

```python
squares = [number**2 for number in range(1, 6)]  # [1, 4, 9, 16, 25]
evens = [number for number in range(1, 11) if number % 2 == 0]
```

То же самое можно написать обычным циклом с `append()` — и для сложных
преобразований обычный цикл читается лучше.
