### Задание 1.1

Заготовка: [`starter/task_1_1.py`](starter/task_1_1.py)

Дан список покупок `["молоко", "сахар", "яйца", "кофе"]`. Выведите первый и последний
товар, количество товаров, затем добавьте в конец «хлеб», удалите «сахар»
и выведите получившийся список.

<details>
<summary>Подсказка</summary>

Последний элемент — это индекс `-1`. Добавляет в конец метод `append()`,
удаляет по значению — `remove()`.

</details>

<details>
<summary>Решение</summary>

```python
shopping = ["молоко", "сахар", "яйца", "кофе"]

print("Первый товар:", shopping[0])
print("Последний товар:", shopping[-1])
print("Всего товаров:", len(shopping))

shopping.append("хлеб")
shopping.remove("сахар")

print(shopping)  # ['молоко', 'яйца', 'кофе', 'хлеб']
```

</details>

### Задание 1.2

Заготовка: [`starter/task_1_2.py`](starter/task_1_2.py)

Дан список `[3, 14, 15, 92, 65, 35, 89, 79]`. С помощью срезов выведите первые три числа,
последние два, каждое второе и список в обратном порядке.

<details>
<summary>Подсказка</summary>

Срез `[:3]` берёт с начала, `[-2:]` — два последних, `[::2]` — с шагом 2,
`[::-1]` — в обратном порядке.

</details>

<details>
<summary>Решение</summary>

```python
numbers = [3, 14, 15, 92, 65, 35, 89, 79]

print("Первые три:", numbers[:3])  # [3, 14, 15]
print("Последние два:", numbers[-2:])  # [89, 79]
print("Каждое второе:", numbers[::2])  # [3, 15, 65, 89]
print("В обратном порядке:", numbers[::-1])
```

</details>

### Задание 1.3

Заготовка: [`starter/task_1_3.py`](starter/task_1_3.py)

Программа просит ввести пять чисел, складывает их в список, а затем выводит сам список,
его длину и сумму чисел.

<details>
<summary>Подсказка</summary>

Заведите пустой список `numbers = []` до цикла и добавляйте в него значения
методом `append()`. Сумму считайте вторым циклом с накоплением (`total += number`).

</details>

<details>
<summary>Решение</summary>

```python
numbers = []

for i in range(1, 6):
    value = int(input(f"Число {i}: "))
    numbers.append(value)

print("Список:", numbers)
print("Чисел:", len(numbers))

total = 0
for number in numbers:
    total += number

print("Сумма:", total)
```

Сумму списка умеет считать и встроенная функция `sum(numbers)` — но важно уметь
написать такой цикл самостоятельно.

</details>

### Задание 2.2

Заготовка: [`starter/task_2_2.py`](starter/task_2_2.py)

Программа спрашивает предложение, выводит количество слов в нём и каждое слово
с новой строки.

<details>
<summary>Подсказка</summary>

`sentence.split()` без аргумента разрезает строку по пробелам и возвращает список.
По этому списку можно пройти циклом `for`.

</details>

<details>
<summary>Решение</summary>

```python
sentence = input("Введите предложение: ")
words = sentence.split()

print("Слов в предложении:", len(words))

for word in words:
    print(word)
```

Если нужна нумерация, заведите счётчик и увеличивайте его в цикле:

```python
number = 1
for word in words:
    print(f"{number}. {word}")
    number += 1
```

</details>

### Задание 2.3

Заготовка: [`starter/task_2_3.py`](starter/task_2_3.py)

**Часть 1.** Соберите из списка `["Анна", "Иван", "Пётр"]` строку `Анна, Иван, Пётр`.

**Часть 2.** Разберите строку `"Б01-123;Б01-124;Б01-125"` в список и выведите количество
групп и сам список.

<details>
<summary>Подсказка</summary>

`join()` вызывается у разделителя: `", ".join(names)`. У `split()` разделитель
передаётся аргументом: `split(";")`.

</details>

<details>
<summary>Решение</summary>

```python
names = ["Анна", "Иван", "Пётр"]
groups_line = "Б01-123;Б01-124;Б01-125"

print(", ".join(names))  # Анна, Иван, Пётр

groups = groups_line.split(";")
print("Групп:", len(groups))  # 3
print(groups)  # ['Б01-123', 'Б01-124', 'Б01-125']
```

</details>

Заготовка: [`starter/task_3_3.py`](starter/task_3_3.py)

Дано меню кафе `{"кофе": 180, "чай": 120, "какао": 200}`. Выведите каждую позицию
в виде `кофе — 180 руб.` и общую сумму цен.

<details>
<summary>Подсказка</summary>

`menu.items()` даёт пары, которые сразу распаковываются в две переменные:

### Задание 4.2

Дан список `[1, 2, 2, 3, 3, 3, 4, 4, 5]`. Выведите только уникальные значения
и их количество.

<details>
<summary>Подсказка</summary>

`set(numbers)` превращает список в множество, а множество не хранит дубликаты.

</details>

<details>
<summary>Решение</summary>

```python
numbers = [1, 2, 2, 3, 3, 3, 4, 4, 5]
unique = set(numbers)

print("Уникальные значения:", unique)  # {1, 2, 3, 4, 5}
print("Сколько уникальных:", len(unique))  # 5
```

Если нужен снова список: `unique_list = list(unique)`.

</details>

### Задание 4.3

Две группы студентов записаны множествами:

```python
group_a = {"Анна", "Иван", "Пётр", "Мария"}
group_b = {"Иван", "Мария", "Ольга"}
```

Выведите тех, кто есть в обеих группах; всех студентов без повторов; тех, кто есть
только в первой группе.

<details>
<summary>Решение</summary>

```python
group_a = {"Анна", "Иван", "Пётр", "Мария"}
group_b = {"Иван", "Мария", "Ольга"}

print("В обеих группах:", group_a & group_b)  # пересечение
print("Все студенты:", group_a | group_b)  # объединение
print("Только в первой:", group_a - group_b)  # разность
```

Порядок вывода может отличаться: множество не хранит порядок элементов.

</details>

### Задание 4.4

Решите три маленькие задачи списочными выражениями:

1. список кубов чисел от 1 до 10;
2. из списка `[12, 7, 30, 3, 25]` — только числа больше 10;
3. из списка слов `["кот", "собака", "ёж"]` — список их длин.

<details>
<summary>Решение</summary>

```python
cubes = [number**3 for number in range(1, 11)]
print(cubes)

numbers = [12, 7, 30, 3, 25]
big = [number for number in numbers if number > 10]
print(big)  # [12, 30, 25]

words = ["кот", "собака", "ёж"]
lengths = [len(word) for word in words]
print(lengths)  # [3, 6, 2]
```

</details>

### Задание 4.5

Программа спрашивает слово и выводит, сколько раз встречается каждая буква.

```
Введите слово: молоко
м: 1
о: 3
л: 1
к: 1
```

<details>
<summary>Подсказка</summary>

Заведите пустой словарь и переберите слово по буквам. Для каждой буквы: если она уже
есть в словаре — увеличьте счётчик, если нет — запишите 1.

</details>

<details>
<summary>Решение</summary>

```python
word = input("Введите слово: ").lower()
counts = {}

for letter in word:
    if letter in counts:
        counts[letter] += 1
    else:
        counts[letter] = 1

for letter, count in counts.items():
    print(f"{letter}: {count}")
```

Короче то же самое записывается через `get()` со значением по умолчанию:

```python
counts[letter] = counts.get(letter, 0) + 1
```

</details>

### Задание 4.6

Программа спрашивает предложение и выводит его слова в обратном порядке:

```
Введите предложение: сегодня хорошая погода
погода хорошая сегодня
```

<details>
<summary>Подсказка</summary>

Три шага: `split()` — разбить на слова, срез `[::-1]` — перевернуть список,
`join()` — собрать обратно в строку.

</details>

<details>
<summary>Решение</summary>

```python
sentence = input("Введите предложение: ")

words = sentence.split()
reversed_words = words[::-1]

print(" ".join(reversed_words))
```

</details>
